Algebra 8 — Functions · Domain and range · Composite and inverse functions

Exercises

Marks in brackets. ★ = harder question. $\text{fg}(x)$ means do g first, then f.

  1. [3]Decide, with a reason, whether each graph shows a function.
    a $y=x^2-1$b the circle $x^2+y^2=4$c $y=\dfrac{1}{x}$

    Use the vertical-line test: a graph is a function if no vertical line meets it more than once. a Yes — every $x$ gives exactly one $y$.  b No — a vertical line through $x=1$ meets the circle at two points ($y=\pm\sqrt3$), so one input has two outputs.  c Yes — one output for every $x$ in its domain ($x\ne0$).

  2. [3]$\text{f}:x\mapsto x^2-2x$. Find, simplifying your answers,
    a $\text{f}(3x)$b $3\text{f}(x)$c $\text{f}(-x)$

    a Replace $x$ by $3x$: $(3x)^2-2(3x)=9x^2-6x$.  b $3(x^2-2x)=3x^2-6x$.  c $(-x)^2-2(-x)=x^2+2x$.

  3. [2]The domain of $\text{f}:x\mapsto x^2+1$ is all real numbers. Write down the range.

    $x^2\ge0$ for every real $x$, so $x^2+1\ge1$: the range is $\text{f}(x)\ge1$ (all real numbers $\ge1$).

  4. [3]State which values of $x$ (if any) must be excluded from the domain of
    a $\text{f}(x)=\sqrt{x+2}$b $\text{f}(x)=x^3$c $\text{f}(x)=\dfrac{5}{2x-1}$

    a No square roots of negatives: need $x+2\ge0$, so exclude $x<-2$.  b None — any real number can be cubed.  c No division by zero: exclude $x=\tfrac12$.

  5. [2]$\text{f}(x)=3x+1$ and $\text{g}(x)=x-4$. Find $\text{fg}(5)$.

    g first: $\text{g}(5)=1$. Then f: $\text{f}(1)=4$. So $\text{fg}(5)=4$.

  6. [4]$\text{f}(x)=(x-1)^2$ and $\text{g}(x)=3x$. Find
    a $\text{fg}(x)$b $\text{gg}(x)$

    a $\text{fg}(x)=\text{f}(3x)=(3x-1)^2$.  b $\text{gg}(x)=\text{g}(3x)=9x$.

  7. [4]Find the inverse function of
    a $\text{f}(x)=\dfrac{x}{3}+2$b $\text{f}(x)=\dfrac{4}{x+1}$

    Write $y=\ldots$, swap $x$ and $y$, make $y$ the subject.

    a $y=\dfrac{x}{3}+2\ \to\ x=\dfrac{y}{3}+2\ \to\ y=3(x-2)$. So $\text{f}^{-1}(x)=3(x-2)=3x-6$.

    b $x=\dfrac{4}{y+1}\ \to\ x(y+1)=4\ \to\ y=\dfrac{4}{x}-1$. So $\text{f}^{-1}(x)=\dfrac{4}{x}-1$ (or $\dfrac{4-x}{x}$).

  8. [4]$\text{f}(x)=2(x-3)$ and $\text{g}(x)=2x+5$. Given that $\text{f}^{-1}(a)+\text{g}^{-1}(a)=4$, find $a$.

    Inverses: $\text{f}^{-1}(x)=\dfrac{x}{2}+3$ and $\text{g}^{-1}(x)=\dfrac{x-5}{2}$. Then $\dfrac{a}{2}+3+\dfrac{a-5}{2}=4\Rightarrow\dfrac{2a-5}{2}+3=4\Rightarrow2a-5=2\Rightarrow a=3.5$. (Check: $\text{f}^{-1}(3.5)=4.75$, $\text{g}^{-1}(3.5)=-0.75$, sum $4$ ✓.)

Total: 25 marks

Check: function = one output for each input (vertical-line test) · $\text{f}(2x)$: substitute $2x$ for every $x$; $2\text{f}(x)$: double the whole thing · domain excludes division by 0 and square roots of negatives · $\text{fg}(x)$ = g first · inverse: swap $x$ and $y$, rearrange.

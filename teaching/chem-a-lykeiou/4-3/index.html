4.3 Συγκέντρωση διαλύματος — αραίωση

Σημειώσεις
  • Συγκέντρωση (molarity, c): εκφράζει τα mol διαλυμένης ουσίας ανά 1 L διαλύματος. Μονάδα το mol/L (ή M).
  • Κατά την αραίωση ενός διαλύματος (προσθήκη διαλύτη), τα mol της διαλυμένης ουσίας δεν αλλάζουν — γι’ αυτό ισχύει η σχέση c₁V₁ = c₂V₂ (βλ. τύπους παρακάτω).
Τύποι
  • Συγκέντρωση: \(c = \dfrac{n}{V}\quad (V\ \text{σε L})\)
  • Αραίωση / ανάμειξη: \(c_1 V_1 = c_2 V_2\)

Φτιάξε διάλυμα και δες τη συγκέντρωση (mol/L) να αλλάζει: πρόσθεσε διαλυμένη ουσία (ανεβαίνει) ή νερό (αραίωση — πέφτει). Επιβεβαίωσε ζωντανά τη σχέση c = n/V.

Ασκήσεις — Συγκέντρωση

Άσκηση 1. Διαλύουμε 0,15 mol NaOH σε νερό και προκύπτει διάλυμα όγκου 300 mL. Να βρεις τη συγκέντρωσή του.

Λύση

Ο όγκος σε L: $V = 300\ \text{mL} = 0{,}3\ \text{L}$.

Τύπος: $c = \dfrac{n}{V} = \dfrac{0{,}15}{0{,}3} = \mathbf{0{,}5\ \text{mol/L}}$.

Άσκηση 2. Αραιώνουμε 100 mL διαλύματος HCl συγκέντρωσης 2 mol/L προσθέτοντας νερό, μέχρι ο όγκος να γίνει 500 mL. Ποια η νέα συγκέντρωση;

Λύση

Στην αραίωση τα mol διατηρούνται: $c_1 V_1 = c_2 V_2$. Λύνοντας ως προς $c_2$:

$c_2 = \dfrac{c_1 V_1}{V_2} = \dfrac{2\cdot 100}{500} = \mathbf{0{,}4\ \text{mol/L}}$ (οι όγκοι σε ίδια μονάδα απλοποιούνται).

Ασκήσεις από Τράπεζα Θεμάτων

Κόλλησες; 10 λεπτά προσπάθεια, μετά η λύση γραμμή-γραμμή.

Άσκηση 1 — Νιτρικό οξύ. Παρασκευάζουμε υδατικό διάλυμα νιτρικού οξέος (HNO₃) συγκέντρωσης 0,1 M (διάλυμα Δ1).
α) Πόσα g HNO₃ περιέχονται σε 100 mL του Δ1;
β) Πόσα mL νερού πρέπει να προσθέσουμε σε 100 mL του Δ1 ώστε να προκύψει διάλυμα Δ2 συγκέντρωσης 0,05 M;
γ) Αναμειγνύουμε 300 mL διαλύματος HNO₃ 0,2 M (Δ3) με 300 mL του Δ1. Βρες τη συγκέντρωση του τελικού διαλύματος Δ4.
Δίνονται Ar: H=1, N=14, O=16.

Λύση

α) mol στο διάλυμα: $n = c\cdot V = 0{,}1\cdot 0{,}1 = 0{,}01\ \text{mol}$. Με $M_r(\text{HNO}_3) = 1+14+48 = 63$: $m = n\cdot M_r = 0{,}01\cdot 63 = \mathbf{0{,}63\ \text{g}}$.

β) Αραίωση (τα mol σταθερά): $c_1 V_1 = c_2 V_2 \Rightarrow V_2 = \dfrac{0{,}1\cdot 100}{0{,}05} = 200\ \text{mL}$. Νερό που προσθέτουμε: $200 - 100 = \mathbf{100\ \text{mL}}$.

γ) Ανάμειξη (τα συνολικά mol διατηρούνται): $c_4 = \dfrac{c_1 V_1 + c_3 V_3}{V_1 + V_3} = \dfrac{0{,}1\cdot 300 + 0{,}2\cdot 300}{600} = \dfrac{90}{600} = \mathbf{0{,}15\ \text{M}}$.

Άσκηση 2 — Υδροχλωρικό οξύ. Διαθέτουμε διάλυμα HCl συγκέντρωσης 0,2 M (Δ1).
α) Πόσα g HCl περιέχονται σε 100 mL του Δ1;
β) Πόσα mL νερού πρέπει να προσθέσουμε σε 100 mL του Δ1 για να πάρουμε διάλυμα Δ2 συγκέντρωσης 0,05 M;
γ) Πόσα mL του Δ1 πρέπει να αναμείξουμε με 200 mL του Δ2 ώστε να προκύψει διάλυμα Δ3 συγκέντρωσης 0,1 M;
Δίνονται Ar: H=1, Cl=35,5.

Λύση

α) $n = 0{,}2\cdot 0{,}1 = 0{,}02\ \text{mol}$, $M_r(\text{HCl}) = 1+35{,}5 = 36{,}5$, άρα $m = 0{,}02\cdot 36{,}5 = \mathbf{0{,}73\ \text{g}}$.

β) Στην αραίωση τα mol διατηρούνται, άρα $c_1 V_1 = c_2 V_2 \Rightarrow V_2 = \dfrac{0{,}2\cdot 100}{0{,}05} = 400\ \text{mL}$. Νερό: $400 - 100 = \mathbf{300\ \text{mL}}$.

γ) Έστω $V_1$ τα mL του Δ1. Διατήρηση mol: $c_1 V_1 + c_2 V_2 = c_3 (V_1 + V_2)$, δηλαδή $0{,}2 V_1 + 0{,}05\cdot 200 = 0{,}1(V_1 + 200)$. Λύνοντας: $0{,}1 V_1 = 10 \Rightarrow V_1 = \mathbf{100\ \text{mL}}$.

Άσκηση 3 — Υδροξείδιο του βαρίου. Διαθέτουμε διάλυμα Ba(OH)₂ συγκέντρωσης 0,01 M (Δ1).
α) Πόσα g Ba(OH)₂ περιέχονται σε 200 mL του Δ1;
β) 150 mL του Δ1 αραιώνονται σε τελικό όγκο 300 mL. Βρες τη συγκέντρωση του Δ2.
γ) Πόσα mL του Δ1 αναμειγνύονται με 200 mL διαλύματος Ba(OH)₂ 0,03 M (Δ3) ώστε να προκύψει διάλυμα Δ4 συγκέντρωσης 0,02 M;
Δίνονται Ar: H=1, O=16, Ba=137.

Λύση

α) $n = 0{,}01\cdot 0{,}2 = 0{,}002\ \text{mol}$. $M_r(\text{Ba(OH)}_2) = 137 + 2\cdot(16+1) = 171$, άρα $m = 0{,}002\cdot 171 = \mathbf{0{,}342\ \text{g}}$.

β) Στην αραίωση ($c_1 V_1 = c_2 V_2$): $c_2 = \dfrac{c_1 V_1}{V_2} = \dfrac{0{,}01\cdot 150}{300} = \mathbf{0{,}005\ \text{M}}$.

γ) $0{,}01 V_1 + 0{,}03\cdot 200 = 0{,}02(V_1 + 200) \Rightarrow 0{,}01 V_1 = 2 \Rightarrow V_1 = \mathbf{200\ \text{mL}}$.

Άσκηση 4 — Καυστική σόδα. Διαθέτουμε δύο διαλύματα NaOH: το Δ1 συγκέντρωσης 1 M και το Δ2 περιεκτικότητας 6% w/v.
α) Ποιο από τα δύο είναι πιο αραιό; Να δικαιολογήσεις.
β) Πόσα mL νερού πρέπει να προσθέσουμε σε 200 mL του Δ1 για να πάρουμε διάλυμα Δ3 συγκέντρωσης 0,4 M;
γ) Αναμειγνύουμε 2 L του Δ1 με 2 L του Δ2. Βρες τη συγκέντρωση του τελικού διαλύματος.
Δίνονται Ar: H=1, O=16, Na=23.

Λύση

α) Μετατρέπουμε το Δ2 σε συγκέντρωση: 6% w/v = 6 g NaOH στα 100 mL. Με $M_r(\text{NaOH}) = 40$: $n = \tfrac{6}{40} = 0{,}15\ \text{mol}$ στα 0,1 L· από τον ορισμό της συγκέντρωσης $c=\dfrac{n}{V}$: $c = \tfrac{0{,}15}{0{,}1} = 1{,}5\ \text{M}$. Επειδή $1 < 1{,}5$, το Δ1 (1 M) είναι πιο αραιό.

β) $c_1 V_1 = c_3 V_3 \Rightarrow V_3 = \dfrac{1\cdot 200}{0{,}4} = 500\ \text{mL}$. Νερό: $500 - 200 = \mathbf{300\ \text{mL}}$.

γ) $c = \dfrac{c_1 V_1 + c_2 V_2}{V_1 + V_2} = \dfrac{1\cdot 2 + 1{,}5\cdot 2}{4} = \dfrac{5}{4} = \mathbf{1{,}25\ \text{M}}$.

Άσκηση 5 — Θειικό οξύ. Διαθέτουμε 2 L υδατικού διαλύματος H₂SO₄ συγκέντρωσης 1,5 M (Δ1).
α) Βρες την % w/v περιεκτικότητα του Δ1.
β) Βρες τη συγκέντρωση μετά την προσθήκη 4 L νερού στο Δ1.
γ) Βρες τη συγκέντρωση του διαλύματος Δ4 που προκύπτει από ανάμειξη 2 L διαλύματος H₂SO₄ 0,5 M (Δ3) με το Δ1.
Δίνονται Ar: H=1, S=32, O=16.

Λύση

α) $M_r(\text{H}_2\text{SO}_4) = 2+32+64 = 98$. Σε 100 mL διαλύματος: $m = c\cdot M_r\cdot V = 1{,}5\cdot 98\cdot 0{,}1 = 14{,}7\ \text{g}$, άρα 14,7% w/v.

β) Αραίωση: $c_2 = \dfrac{c_1 V_1}{V_2} = \dfrac{1{,}5\cdot 2}{2+4} = \dfrac{3}{6} = \mathbf{0{,}5\ \text{M}}$.

γ) $c_4 = \dfrac{c_1 V_1 + c_3 V_3}{V_1 + V_3} = \dfrac{1{,}5\cdot 2 + 0{,}5\cdot 2}{4} = \dfrac{4}{4} = \mathbf{1\ \text{M}}$.

Άσκηση 6 — Χλωριούχο βάριο. Παρασκευάσαμε 200 mL υδατικού διαλύματος BaCl₂ συγκέντρωσης 0,2 M (Δ1).
α) Πόσα g BaCl₂ περιέχονται στο Δ1;
β) Σε 40 mL του Δ1 προσθέτουμε 60 mL νερού. Βρες τη συγκέντρωση του Δ2.
γ) Αναμειγνύουμε 100 mL του Δ1 με 100 mL διαλύματος BaCl₂ 0,3 M (Δ3). Βρες τη συγκέντρωση του Δ4.
Δίνονται Ar: Cl=35,5, Ba=137.

Λύση

α) $n = 0{,}2\cdot 0{,}2 = 0{,}04\ \text{mol}$, $M_r(\text{BaCl}_2) = 137 + 2\cdot 35{,}5 = 208$, άρα $m = 0{,}04\cdot 208 = \mathbf{8{,}32\ \text{g}}$.

β) Τελικός όγκος $40+60 = 100\ \text{mL}$. Στην αραίωση ($c_1 V_1 = c_2 V_2$): $c_2 = \dfrac{c_1 V_1}{V_2} = \dfrac{0{,}2\cdot 40}{100} = \mathbf{0{,}08\ \text{M}}$.

γ) $c_4 = \dfrac{0{,}2\cdot 100 + 0{,}3\cdot 100}{200} = \dfrac{50}{200} = \mathbf{0{,}25\ \text{M}}$.

Πηγή: Ι.Ε.Π., Τράπεζα Θεμάτων Διαβαθμισμένης Δυσκολίας (θέματα 11847, 11848, 11849, 11857, 11852, 11850). Οι εκφωνήσεις έχουν αναδιατυπωθεί.
